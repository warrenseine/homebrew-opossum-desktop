# homebrew-opossum-desktop

Homebrew tap for [Opossum Desktop](https://github.com/warrenseine/opossum-desktop).

```bash
brew install --cask warrenseine/opossum-desktop/opossum-desktop
```

The app is unsigned (no Apple Developer ID yet) — see the cask's caveat for the one-time
Gatekeeper approval step.
